# Toy project: age at first birth and health

A tiny project for practising git. All data are simulated: `sim_data.csv` was made by `simulate_data.R`.

Open `toy-project.Rproj` in RStudio (or this folder in VS Code) and run:

```r
source("analysis.R", echo = TRUE)
```

It fits a linear regression of a health score on age at first birth.
