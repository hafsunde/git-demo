# Git and GitHub for researchers

Material for a 1-hour session at the CeFH Ung 2nd Annual Young Researchers Workshop (18 November 2026), for PhD candidates and postdocs who analyse data in R (or Stata) and write in Markdown/LaTeX.
Everything is done with the buttons in VS Code and RStudio.

## For participants

| File | What it is |
|---|---|
| [participants/exercise-1-setup.md](participants/exercise-1-setup.md) | Exercise 1: install git, tell git who you are, clone this repo. (Also on the slides.) |
| [participants/exercise-2-github.md](participants/exercise-2-github.md) | Exercise 2: GitHub account, new repo, clone, commit, push (VS Code or RStudio). |
| [participants/cheatsheet.md](participants/cheatsheet.md) | One page: the words, and which button does what. |
| [slides/](slides/) | The slides (Quarto). |
| [example-project/](example-project/) | A toy project for the demo: one simple regression script. |

## For the presenter

- [workshop-plan.md](workshop-plan.md): agenda, demo script, open decisions and checklist.
- Render slides: open `slides/slides.qmd` in RStudio/VS Code and click *Render*. Press `S` in the browser for speaker notes.
